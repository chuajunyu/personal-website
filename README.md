# personal-website

Personal site for [chuajunyu.com](https://chuajunyu.com), built with [Astro](https://astro.build/) and designed to look like a Nutrition Facts label.

## Commands

| Command         | Action                                       |
| :-------------- | :------------------------------------------- |
| `yarn install`  | Install dependencies                         |
| `yarn dev`      | Start local dev server at `localhost:4321`   |
| `yarn build`    | Build the production site to `./dist/`       |
| `yarn preview`  | Preview the build locally before deploying   |
